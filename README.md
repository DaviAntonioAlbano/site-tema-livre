## Descrição do site

O Mundo Minecraft é um site informativo sobre o jogo Minecraft, apresentando sua história, características, modos de jogo, criaturas e recursos. O projeto possui cinco páginas HTML, com informações organizadas em textos, listas, imagens, tabela e formulários. O objetivo é apresentar o universo do jogo utilizando HTML sem CSS.

## Como abrir o projeto

1. Baixe ou clone o repositório para o computador.
2. Extraia os arquivos, caso estejam compactados.
3. Abra a pasta do projeto.
4. Localize o arquivo `index.html`.
5. Clique duas vezes nele para abrir no navegador.

Não é necessário instalar programas adicionais para visualizar as páginas.

## Páginas do site

- **index.html — Início:** apresenta Minecraft, seus modos de jogo, recursos e imagens ilustrativas.
- **sobre.html — Sobre:** explica a história, a jogabilidade, os biomas e apresenta um glossário de termos.
- **dados.html — Dados:** apresenta uma tabela com informações sobre criaturas e atualizações do jogo.
- **cadastro.html — Cadastro:** contém um formulário demonstrativo para uma atividade temática de Minecraft.
- **contato.html — Contato:** apresenta informações fictícias de contato, horário de atendimento e formulário de mensagens.

## Acessibilidade

Foram utilizados recursos de acessibilidade em todas as páginas:

- Idioma definido como português do Brasil (`lang="pt-BR"`).
- Link para pular diretamente ao conteúdo principal.
- Estrutura semântica com `header`, `nav`, `main`, `section`, `article`, `aside` e `footer`.
- Hierarquia de títulos organizada.
- Textos alternativos nas imagens (`alt`).
- Rótulos associados aos campos dos formulários por meio de `label`, `for` e `id`.
- Identificação da página atual no menu com `aria-current="page"`.
- Tabelas com títulos e identificação de cabeçalhos.
- Formulários com campos identificados e validação HTML.

### Teste de teclado

O teste deve ser realizado utilizando a tecla `Tab` para navegar pelos links, campos e botões, e `Enter` ou a barra de espaço para ativar os elementos.
